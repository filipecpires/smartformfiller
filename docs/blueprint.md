# **App Name**: Smart Form Filler

## Core Features:

- Template Creation: Define document template with customizable fields (text, date, dropdown, etc.).
- Document Upload: Allow users to upload documents for processing using defined templates.
- AI-Powered Field Filling: Use AI to analyze the uploaded document and pre-fill the template fields. This feature uses an LLM to act like a tool which uses reasoning to decide if some piece of information belongs in an output field.
- Form Display and Editing: Display the filled form to the user for review and editing.
- PWA Install Prompt: Prompt the user to add the app to the home screen as a PWA.
- Multi-Language Support: Multi-language support, with Portuguese as the primary language.

## Style Guidelines:

- Primary color: Neutral gray (#F5F5F5) for a clean, professional look.
- Secondary color: Light blue (#E3F2FD) for accents and highlights.
- Accent: Teal (#008080) for CTAs and interactive elements.
- Clean and modern sans-serif font for form fields and labels.
- Simple, recognizable icons for actions like upload, edit, and save.
- Clear and structured form layout with distinct sections for each field.
- Subtle animations to indicate loading and processing states.
